    History & storage
    
        
    
          Keep the most recent events within the size, count and age limits.
          These limits do not remove XP, reported usage, or unanswered requests.
        
    
        
    
        
    
        
    
          The database also stores live sessions and usage totals, outside the
          event history limit.
        
    
        
    
          Observer storage details
          
    
            Automatic history pruning is paused until settings can be read.
          
    
          
    
          
    
          
    
            Retention limits apply to raw event history. The database also keeps
            usage correction records and live state. Inbox totals already
            include processed files awaiting cleanup and temporary publications;
            these rows are not additive.
          
    
          
    
            Unprocessed events and temporary publications are kept for safe
            retry. Legacy logs are read without truncation. A settings change
            does not remove those files.

    A little orientation
    
      
    
        This office observes your coding agents by default. Tasks → Local runs
        can start a fresh Codex, Claude Code, or OpenCode task only after you
        enable the local runner. Existing sessions and approvals stay in the
        original runtime. Room toys do not run agent commands.
      
    
      
    Connect a runtime
    
      
    
        Open the Connection guide to choose a runtime. Preview setup with
        python3 install.py --dry-run, then connect only what you
        use with --only. Restart the runtime and keep
        python3 run.py open. The installer detects Hermes,
        OpenCode, Claude Code, Codex, Gemini CLI, and the VS Code view.
      
    
      
    
        The demo runs in a temporary directory and is marked DEMO. Its XP
        and events are separate from your real sessions.

        CONNECTION CHECK
        
    
      
    
      
      
        
    1. 
          
      Start the observer
      
          
      
            In your Agent Office checkout, run this and keep the terminal open.
          
      
          
      
            python3 run.py
          
      
        
      2. 
        
    2. 
          
      Connect your runtime
      
          
      
            In a second terminal, connect only the runtime selected above.
            Review its output, then restart that runtime. Add --dry-run to
            inspect the plan without changing configuration.
          
      
          
      
            python3 install.py
          
      
          
      
        
      3. 
        
    3. 
          
      Start a session and use a tool
      
          
      
            Your agent appears after its first recorded event. Select its desk
            or open Agents to inspect the current tool and recent activity.
          
      
        
      4. 
      
    
      
    
        
    Optional Codex usage reports
    
        
    
          From the repository root, import an existing complete
          codex exec --json capture. Hooks handle lifecycle
          activity; this importer adds reported token counts.
        
    
        
    
          python3 codex/stream.py --stream-id build-check-01 <
            build-check-01.jsonl
          
        
    
        
    
          Use one unique name per captured invocation, and reuse it only for the
          same capture. Include thread and turn boundaries. Interactive
          transcript usage and cost are not reported by this adapter.
        
    
      
    
      
    
      
    
        No activity yet?
        
    
          Check the installer output and restart the runtime. The server and
          runtime must share the same HERMES_HOME. Without it, both
          use ~/.hermes.
        
    
        
    
          Connected means the observer is reachable. It does not confirm that a
          runtime is installed. Quiet sessions eventually leave the room; they
          are not persistent employees.
        
    
      
    
      
    
        Approvals, questions and demo mode
        
    
          When an agent needs input, select the button above the floor to
          inspect it. Respond in the original runtime. This office never
          approves a command.
        
    
        
    
          Try python3 demo_feed.py for a separate, clearly labeled
          demo at port 8114. Its activity and XP stay separate from your real
          sessions.
